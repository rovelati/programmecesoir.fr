**[ProgrammeCeSoir.fr](https://programmecesoir.fr/)** est le guide TV moderne, fluide et ultra-rapide dédié à la télévision française et aux chaînes de la TNT. Retrouvez en un instant ce qui passe à la télé en ce moment (**[Programme TV En Direct](https://programmecesoir.fr/en-direct/)**), les programmes en prime time et deuxième partie de soirée (**[Programme TV Ce Soir](https://programmecesoir.fr/)**), ainsi que la grille complète du lendemain (**[Programme TV Demain](https://programmecesoir.fr/demain/)**).

## 🌟 Fonctionnalités Principales

- ⚡ **Vitesse Instantanée (Astro SSG + Cloudflare Edge)** : Affichage ultra-rapide avec Core Web Vitals optimisés pour mobile et desktop.
- 📡 **Grille Complète TNT & Câble/Satellite** : Palmarès exhaustif des chaînes gratuites et payantes de la télévision française avec mise à jour continue.
- 🎬 **Sélections Thématiques Spécialisées** :
  - 🍿 **[Films ce soir à la télé](https://programmecesoir.fr/film-ce-soir/)** — Tous les longs-métrages diffusés ce soir avec résumés, affiches HD, note et casting.
  - 📺 **[Séries TV ce soir](https://programmecesoir.fr/series-ce-soir/)** — Épisodes inédits, saisons et rediffusions.
  - ⚽ **[Sport ce soir](https://programmecesoir.fr/sport-ce-soir/)** — Football (Ligue 1, Ligue des Champions), Rugby, Tennis, F1, Cyclisme et événements sportifs.
  - 🌍 **[Documentaires ce soir](https://programmecesoir.fr/documentaires-ce-soir/)** — Découverte, histoire, nature et société.
  - 📰 **[Infos & Magazines ce soir](https://programmecesoir.fr/infos-ce-soir/)** — Journaux télévisés (JT 20h), reportages et débats d'actualité.
- 🔴 **Direct & Direct Streaming** : Suivi en direct du temps restant par émission et redirection vers les plateformes de streaming officielles (*TF1+, france.tv, 6play, Arte.tv, myCANAL*).

## 🛠️ Stack Technique & Architecture

- **Générateur Statique** : [Astro](https://astro.build/) en mode SSG haute performance pour un temps de réponse minimal.
- **Base de Données EPG** : PostgreSQL haute disponibilité avec pipeline d'enrichissement automatique TMDB et TVmaze.
- **Hébergement & CDN** : Cloudflare Pages avec cache distribué mondial.
- **Données Structurées & SEO** :
  - Balisage `schema.org` complet : `BroadcastEvent`, `TVChannel`, `Movie`, `TVSeries`, `TVEpisode`, `ItemList`, `FAQPage`, `BreadcrumbList`.
  - Notifications en temps réel via **IndexNow** et **Google Indexing API / WebSub**.
  - Génération quotidienne des sitemaps XML (`sitemap-channels.xml`, `sitemap-programmes.xml`).

## 🚀 Installation & Développement Local

```bash
# Cloner le dépôt
git clone https://github.com/rovelati/programmecesoir.fr.git
cd programmecesoir.fr

# Installer les dépendances du frontend Astro
cd astro
npm install

# Lancer le serveur de développement
npm run dev

# Générer la version statique de production
npm run build
```
